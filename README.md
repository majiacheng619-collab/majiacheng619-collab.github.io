## 我的游戏重构与验证

当前游戏源码版本为 7.0.0。我在 `portfolio-source/game-runtime/` 维护游戏运行源码，用 `portfolio-source/game_release.py` 为脚本、样式、图标和启动依赖生成内容哈希，并生成离线缓存。网页图标与安装图标使用同一个萌芽标识。

花园旅程按清晨、正午、黄昏、夜战排列 4 个世界、20 关；完成前一关后解锁下一关，已完成关卡可重玩，未解锁关卡不可进入。出战前的简报展示本关目标、波次、成长时间和已知来客，尚未遇见的敌人保留为未知来客。阵容页支持按职能筛选与文字搜索，先选卡槽再替换植物，并可使用本关推荐阵容；开始后的换卡会重新开局。战后复盘展示守护时间、击退数量、开花、收获阳光、雨露次数、守门员使用与完成波次，并给出下一步建议。

战术雨露在开局累计 15 秒战斗时间后就绪，施放后冷却 45 秒。选择一条已开放路线，可为该路受伤植物恢复最多各自最大生命的 30%，并使该路可见的地面敌人减速 5 秒；不消耗阳光，不揭开迷雾，也不影响飞行或地下敌人。没有有效目标时不能施放；暂停、波间增益选择和未完成教学期间不能施放。它与波间增益中每波赠送阳光的“雨露”是两个独立效果。

6.0、6.3、6.4 的有效回放分别交给冻结的历史规则执行，并核对版本及数据哈希；7.0 新战局记录雨露命令及施放时刻。旧战局恢复时保留战场并迁移到当前规则，但不把迁移前后的混合规则伪装成可复现回放；重新开局后可保存当前规则回放。回放页面的实现统一在 `game-runtime/garden-replay-page.js`，页面引用与离线缓存使用同一份内容哈希资源。
