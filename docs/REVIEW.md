# 个人站改版验收

## 改版前

- 基线为 `pre-redo`（`7d894c5`）的发布归档。线上 `release.json` 标识为 `2026-11-20-ios27-publication`。通过逐页 HTTP GET 比较，42 个 HTML 地址与归档逐字节一致。
- 首页、经历、作品、联系、荣誉、萌芽保卫队案例、面包挑战和冰之圣殿均使用旧的展示壳。英文页、纯文字页、离线页、404 和旧作品入口也在线。无尾斜杠的 `/experience`、`/projects`、`/contact`、`/projects/sprout-patrol` 均能到达对应旧页。不存在的路径返回旧版 404。另有 26 个《萌芽保卫队》游戏应用页面，与作品案例页分别核对。
- `/standby/`（展台）、`/story/`（一分钟故事）和 `/updates/`（近况）仍在独立发布。旧发布文本版为 `/plain/`，英文版为 `/en/`。

### 处理范围

个人站的 12 个内容与系统页面使用同一个 HTML 模板。展台、一分钟故事、近况和旧作品入口改为保留深链接的跳转。其中近况归入首页的面包挑战。独立游戏及其 26 个页面保留游戏自身资源和存档兼容性，作品案例页使用个人站的新壳。

### 第一轮复看

360 首屏发现丝带与人像下颌相交，原生展开控件在 WebKit 上显示为橙色箭头，作品标题和按钮分占两行，指标短标签也没有充分利用可用宽度。第二轮缩小并移开丝带，调整指标措辞，将作品标题直接作为链接，并统一展开控件文字样式。

### 加载性能

旧发布归档的移动端首页三次 Lighthouse 取中位数，性能 61，FCP 0.99 秒，SI 8.09 秒，LCP 2.03 秒，TBT 9,339 毫秒，CLS 0，benchmarkIndex 2334.5。慢点集中在首屏主线程阻塞和视觉完成时间。旧轨迹中的长任务没有可靠的脚本归因。首页此前加载 114,420 字节的 CSS 和 93,349 字节的交互脚本，并在首屏运行实时装饰。

新版移除首屏开场、持续装饰、玻璃计算、浮层与影片脚本。作品图保留尺寸和延迟加载，并生成手机使用的小图。共享 CSS 约 12 KB，脚本 3,560 字节，冰之圣殿只在作品页按需播放。

Lighthouse 采用 Chromium 153 多进程、移动模拟节流。12 个个人站页面的性能均 ≥96，无障碍均为 100。首页测了三次，性能中位数 96，FCP 0.75 秒，LCP 1.14 秒，SI 0.97 秒，TBT 220 毫秒，CLS 0，benchmarkIndex 2254。原始分项见 [Lighthouse 采样](review/lighthouse-mobile.json)。早期单进程探测缺少 Speed Index 所需帧，未用于评分。

### 响应式与保留功能

- Playwright WebKit 在 360×800、393×852、430×932 截取了 42 个地址的首屏与整页，每个版本 252 张。查看了新版各页面的三种首屏及整页对比。主要内容模板调整后重新拍摄。参见 [对比索引](review/README.md)。
- 12 个个人站页面在三个尺寸下进行坐标和触控检查。默认字号下没有横向滚动和正文遮挡，站点提供的交互目标均至少 44×44 CSS 像素。原生影片内部控件由浏览器绘制。
- 纯文字、英文、自动深浅模式与加大字号可用。禁用 JS 和人为延迟样式、图片时分别做了首屏检查。测试通过离线回退、等候中的版本更新和新页面加载。
- Nu HTML Checker 校验 42 个 HTML 页面，零错误。发布树的内部引用和全部媒体指纹校验通过。当前简历与仓库原件逐字节一致。66 项独立游戏及存档测试通过。
