存档迁移Move your save

在原设备导出存档码，再到新设备导入。Take your progress with you using a save code. Export it first, then import it on your new device.

01 · 在原设备导出01 · Export on this device

进入花园，打开设置中的“带走你的院子”，复制存档码，保存在你信任的位置。Enter the garden and open Settings → Take your garden with you. Copy the save code and keep it somewhere you trust.

02 · 在新设备导入02 · Import on the next device

在新设备打开同一游戏，在相同设置中粘贴存档码。导入前会自动备份当前设备进度。Open this game on your next device and paste the code into the same settings panel. Your current progress is backed up before import.

先保存，再清理浏览器。Save before clearing your browser.

当前进度保存在本机浏览器。清理网站数据、更换浏览器或设备前，请先导出存档码。云同步与账号服务暂未开放。Progress is stored in this browser. Export a save code before clearing site data or changing browsers and devices. Cloud sync and accounts are not currently available.
